# Renderster MCP

Turn long videos into captioned vertical clips, dub them into 16 languages, transcribe them or edit them automatically, right from your AI.

Renderster turns long videos into ready-to-post content from a chat. Paste a link from YouTube, TikTok, Instagram, X or Facebook, a direct .mp4, or upload a file, and ask your assistant for what you need: short vertical clips of the best moments with burned-in word-by-word captions, titles, hooks and hashtags; the video dubbed over the original sound with an SRT of the new speech; a timestamped transcript (SRT, VTT, JSON); the whole video edited automatically (silences and retakes cut, captions, zooms, music); or a video made from images, a template or a JSON description.

Jobs run on your Renderster account and use its credits: a clips job is 7 credits for up to 12 clips whatever the video's length, a transcript 2, dubbing 5 per minute. Every result comes back as a link to the finished file. Free plan with 60 credits and one free clips job. This is a hosted remote server: there is nothing to install.

## Connect

- **Server URL:** `https://mcp.renderster.com/mcp`
- **Transport:** Streamable HTTP
- **Auth:** OAuth 2.1 (dynamic client registration and PKCE), or your Renderster API key as a Bearer token

**Claude (claude.ai or Claude Desktop):** Settings → Connectors → Add custom connector → paste the URL → Connect → Allow.

**ChatGPT:** Settings → Apps → Advanced → Developer mode, then add a connector with the URL above and OAuth → Allow.

**Claude Code:**

```bash
claude mcp add --transport http renderster https://mcp.renderster.com/mcp
```

**Cursor, VS Code and other clients** (`mcp.json`):

```json
{
  "mcpServers": {
    "renderster": { "url": "https://mcp.renderster.com/mcp" }
  }
}
```

## Tools

| Tool | What it does |
|---|---|
| `clip_video` | Cuts a long video into short captioned clips with titles, hooks, hashtags and a virality score |
| `edit_clip` | Adjusts one clip (start, end, title, a caption line) and renders it again |
| `dub_video` | Dubs a video into another language over the original sound, with an SRT of the new speech |
| `transcribe_video` | Timestamped transcript with SRT and VTT files |
| `auto_edit` | Edits a talking video automatically: silences and retakes cut, captions, zooms, music |
| `learn_edit_style`, `list_edit_styles` | Learns an editing style from reference videos and lists your styles |
| `create_slideshow_video` | Makes a video from images, with captions and music |
| `render_template`, `list_templates` | Renders a video from a template |
| `render_video`, `preview_video` | Renders any composition from JSON; free 480p preview |
| `create_motion_video` | An animated, narrated video from a description |
| `generate_video` | New footage generated by AI from a prompt (Pro and Business) |
| `download_video` | Downloads a video you own or have the rights to (API-key clients) |
| `get_job`, `list_jobs`, `cancel_job` | Status, list and cancellation of your jobs |
| `upload_files`, `create_upload_link`, `list_uploads` | Bring your own files into the chat |
| `get_account` | Plan, credit balance and what each action costs |

Every tool declares `readOnlyHint`, `destructiveHint` and `openWorldHint`; only `cancel_job` is destructive. Text that comes from a video (title, transcript, clip texts) is returned fenced as untrusted content.

Full API reference: https://renderster.com/docs · Guide for agents: https://renderster.com/llms.txt
